# store/raw — verbatim captures (immutable)

Every source enters here first, exactly as captured. **Never edit these files.** They are the audit trail behind every principle.

- Contents: the raw text/transcript + provenance header (url, author, accessed date).
- Referenced by `Recipe.provenance.raw_ref` and `Source.raw_ref`.
